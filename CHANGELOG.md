# Changelog

## [1.0.1] - 2026-09-12

### Fixed
- Removed the `:has()` selector flagged by the theme linter; unresolved links in the editor now style the underline span directly (same dashed grey result).

## [1.0.0] - 2026-09-12

### Added
- First release. Halftone paper, a hard black panel with an offset shadow around every note, Bangers headlines (yellow-drop H1, red H2), Comic Neue body — fonts embedded.
- Callouts as speech bubbles: rounded bubbles for tips, yellow caption boxes for notes, WHAM! burst boxes for warnings, italic bubbles for quotes, collapsible question bubbles.
- Pink sticker tags (tilted in Reading view), yellow offset-shadow highlights, black narration-box code blocks with a red shadow and pink flair in both Reading view and the editor, Bangers table headers, 3px boxed checkboxes.
- Comic chrome: cyan tab strip with boxed tabs, yellow ribbon with round badge buttons, yellow status bar, red Bangers folder names and a POW! in the file explorer, offset-shadow menus, modals and tooltips.
- Day mode (printed on newsprint) and night mode (printed on black, white ink lines).
